# AI & Third-Party Resources Disclosure

The HackYeah rules require disclosing significant use of AI tools, external models, APIs, datasets and libraries. This file is the single source of truth: update it whenever a dependency is added.

## Work done during HackYeah
All code, prompts, designs and documents in this repository were created during HackYeah 2026. Nothing was prepared before the event. The repository started from an empty commit with a README and `.gitignore`.
